## How to Run
1. Clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run the JavaScript file using Node.js:

   `node main.js`

5. Alternatively, open `index.html` in your browser using Live Server.
6. Press F12 and select Console to view the output.
